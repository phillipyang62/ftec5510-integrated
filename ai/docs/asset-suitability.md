# 五维画像与币种匹配

## 问卷怎么划分用户

现有问卷有 30 道计分题，每个维度 6 道。分数归一到 0–100，按以下权重计算综合分 RAI。

- **FC 财务承载力，35%**。收入稳定性、资产负债、流动储备和大额支出。用于判断能承受多大的损失。
- **RA 风险意愿，25%**。能接受的年度亏损、持仓下跌时的反应和收益偏好。用于判断愿意承受多大的波动。
- **KE 认知与经验，15%**。投资经历、产品复杂度和对风险概念的掌握。用于判断能否理解币种机制，或是否先安排投教。
- **BD 行为纪律，10%**。追涨杀跌、择时自信及执行计划的习惯。投机性较强的示例设置更高的纪律门槛。
- **OC 目标与约束，15%**。投资期限、近期用款、目标是否可调整及借贷情况。用于检查资金用途和可承受的期限。

综合分在 24、44、64、79、100 分处分为 C1 至 C5，分别对应 R1 至 R5 的产品上限。原规则还使用财务承载力封顶和红旗封顶。匹配复用已保存的五维分数和等级。

## 模拟匹配顺序

1. 尚无测评、知识分偏低或测评需要复核时，候选清单为空。USDC 和 RLUSD 的一般投教内容可阅读。目标与约束（OC）不足时，示例会解释模拟练习门槛。
2. 对可查看候选的用户，先比对产品 R 档与客户的产品上限，再逐项检查 FC、RA、KE、BD、OC。页面和聊天解释未达标的维度。
3. 下单页展示目录中的全部模拟现货币种。买入预览提示超档或维度不足，用户可确认模拟订单。价格、余额和可成交数量由中台校验。

例如，`demo_c1` 的 OC 为 20.83，可阅读稳定币课程。USDC 的模拟买入预览会单独提示 OC 的 45 分门槛。`demo_c3` 可匹配 ETH。同为 C5 的用户，行为纪律低于 85 分时，PEPE 不进入模拟候选。

## 0–4 级五维门槛

目录版本为 `classroom-v2`。统一使用 **0 级无门槛、1 级基础（30 分）、2 级中等（45 分）、3 级较高（60 分）、4 级很高（85 分）**。产品 R 档与用户上限用于判断总体风险，数字等级用于检查各维度。

以下按 **FC / RA / KE / BD / OC** 排列。

- **稳定币投教**。USDC 为 **0 / 0 / 0 / 0 / 2**，RLUSD 为 **0 / 0 / 0 / 0 / 3**。模拟练习只设 OC 的单项目标门槛，用来检查资金使用期限、近期用款、借贷和赎回约束。
- **主流波动资产**。ETH 为 **2 / 1 / 2 / 3 / 2**，BTC 为 **3 / 2 / 3 / 3 / 3**。资产回撤需要一定承载力，风险意愿门槛相对较低，纪律和期限约束门槛较高。
- **公链与协议代币**。SOL、XRP、ADA、LINK、AVAX 为 **2 / 4 / 4 / 4 / 4**，SUI、MON 为 **3 / 4 / 4 / 4 / 4**。除了承担损失，还要理解协议、供应变化和交易条件，并能按计划处理波动。
- **投机性较强的代币**。DOGE、PEPE 为 **4 / 4 / 4 / 4 / 4**，五项各至少 85 分。

等级和阈值是课堂筛选规则。市场波动率与流动性需要用独立历史数据和订单簿深度评估。稳定币的目标是锚定美元，仍有脱锚、发行方、平台、链路和赎回风险。USDT 计价接近 1 不能单独证明美元锚定。

## 13 个模拟现货币种及标签依据

**稳定币投教**

- **USDC · R1**。认识美元锚定、发行方、赎回资格和脱锚。[Circle 风险说明](https://www.circle.com/legal/usdc-risk-factors)
- **RLUSD · R2**。阅读储备、赎回条件、地址冻结和脱锚，模拟练习侧重目标期限和赎回约束。[Ripple 稳定币条款](https://ripple.com/legal/stablecoin/)

**主流波动资产**

- **ETH · R3**。现货回撤、链上费用和智能合约生态。这一档沿用项目原来的课堂设定。[Ethereum 资产说明](https://ethereum.org/what-is-ether/)
- **BTC · R4**。价格回撤、工作量证明和交易确认，强调财务承载力、风险意愿和纪律。[Bitcoin 使用提示](https://bitcoin.org/en/you-need-to-know)

**其他公链和协议代币**

- **XRP · R4**。账本原生资产、账户储备和交易费用，关注余额可用性。[XRP Ledger 储备说明](https://xrpl.org/docs/concepts/accounts/reserves)
- **ADA · R4**。供应量上限、社区治理和资金使用期限。[Cardano 宪章](https://cardano.org/constitution/)
- **LINK · R4**。预言机服务和代币用途，提高知识门槛。[Chainlink 文档](https://docs.chain.link/docs/getting-started)
- **SOL · R5**。权益证明、通胀发行和生态风险，提高承载力和风险意愿门槛。[Solana 质押与发行说明](https://solana.com/staking)
- **AVAX · R5**。费用销毁、奖励发行及其对供应的影响。[Avalanche 代币机制](https://support.avax.network/en/articles/6912428-tokenomics-faq)
- **SUI · R5**。较新的公链生态和分期代币释放，提高信息核查和纪律门槛。[Sui 代币释放安排](https://www.sui.io/token-schedule)
- **MON · R5**。较新的 EVM 兼容公链和交易场所核查，提高知识、目标约束和承载力门槛。公开模式的 MON/USDT 来源为 OKX。[Monad 网络文档](https://docs.monad.xyz/developer-essentials/network-information) · [OKX 上线说明](https://www.okx.com/en-gb/help/okx-to-list-mon-monad-for-spot-trading)

**模因与投机性较强的示例**

- **DOGE · R5**。模因与支付用途、持续发行和追涨行为，提高纪律门槛。[Dogecoin 发行说明](https://dogecoin.com/dogepedia/faq/dogecoin-inflation/)
- **PEPE · R5**。模因定位、匿名团队和用途证据有限，对承载力和纪律要求较高。[Binance Research 的 PEPE 资料](https://www.binance.com/en/research/projects/pepe)

全部交易对以 USDT 计价。离线模式为 13 个币种提供明确标记的模拟报价。混合行情模式下 BTC 和 ETH 沿用组内随机模拟器，其余币种读取公开接口。公开报价不足时，中台返回相应的可用性状态。

## 本机验证

在克隆仓库根目录运行 `python run_demo.py`。用 `demo_c1` 登录，在聊天助手问「哪些币种适合我」，或从测评结果页查看对应投教。切到 `demo_c3` 或 `demo_c5`，在「模拟下单」页选不同币种，检查产品标签、匹配理由、报价、图表和订单预览。

在根目录运行 `python -X utf8 check_integration.py` 可复跑问卷、匹配、13 个交易对的模拟成交和成交历史检查。
